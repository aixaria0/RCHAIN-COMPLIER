# M25 — Active Gate Counterfactual

## Question

M21/M22 established that an existing sender-set predicate is absent from the active `block_summary` path. M24 established that the anomalous fringe is not spontaneously generated by clean proposer scheduling within the bounded search.

M25 asks:

> At the real active admission boundary, what is the smallest additional discriminator that rejects the observed witness while preserving a valid one-message-per-bonded-sender control?

## Exact setup

Pinned revision:

```text
rchain-community/rchain-rust@d92f0787a6096cd6d79864ec2d7c1dd9b6912d0b
```

The exact upstream `block_summary` implementation is not modified. The test adds a shadow predicate over the same real `BlockDagStorage` justifications:

```text
distinct(justification.senders) == distinct(positive-stake bonded senders)
```

The current active path is evaluated first, then the shadow predicate is evaluated on the same candidate and DAG.

## Expected differential

```text
duplicate / missing bonded sender
    current block_summary -> Ok(())
    shadow sender-set gate -> reject

one-message-per-bonded-sender control
    current block_summary -> Ok(())
    shadow sender-set gate -> accept
```

The shadow gate is intentionally not presented as an upstream patch. It is a characterization of the smallest discriminator for this specific witness.

## Scope

M25 does not prove that sender-set equality is the complete Casper specification, nor that it is the only compatible remediation. It tests the narrow compatibility question created by the observed implementation gap.

Together with M24, the current research boundary becomes:

```text
clean proposer search
      -> no spontaneous under-cardinality witness
      |
adversarially shaped input
      -> active block_summary admits
      -> persisted DAG retains
      -> next proposal preserves
      |
existing sender-set discriminator
      -> rejects the observed missing-sender shape
```
