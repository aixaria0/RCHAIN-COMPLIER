One invariant above all

A claim must not become stronger merely because it moved through another tool.

Hash integrity is not truth. Signature validity is not trust. Quorum count is not protocol finality. A synthetic witness is not a live exploit. Native replay is implementation-conformance evidence at the pinned revision—not production-wide safety.
